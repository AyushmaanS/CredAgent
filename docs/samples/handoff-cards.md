# Sample handoff cards

Generated by `scripts/sample_cards.py` from real offline runs against the fake provider (headless Chrome, the scripted stand-in for the model, a harness playing the person). The text is exactly what the terminal shows; only the local port is replaced with `PORT`. Every card has the six fields required by PRD §9: done so far, blocking + evidence, what to do and where, what the agent does next, how to resume, and what not to do.

## DO: terms checkbox (the agent filled the form; only the person accepts terms)

Scenario: `terms_checkbox` · try it: `.venv/bin/credagent get Fakeprov --fake-provider terms_checkbox --offline`

```text
==============================================================================
  ACTION NEEDED IN THE BROWSER (DO) · run a-terms_checkbox
==============================================================================
  1. Done so far:  7 actions by the agent, 0 by you
  2. Blocking:     Submitting this form accepts terms (checkbox or implied
                   wording); the person reviews and submits.
     Evidence:     [observed] checkbox: "I have read and agree to the
                   Fakeprov Developer Terms"
                   (http://127.0.0.1:PORT/apps/new)
  3. What to do:   In the browser window: read the terms, tick “I have read
                   and agree to the Fakeprov Developer Terms”, then click
                   “Create app”. If you do not agree, press Ctrl+C: nothing
                   is submitted and the run is saved. The agent filled:
                   “Application name”, “Description”, “Homepage URL”,
                   “Authorization callback URL”. Where: the CredAgent Chrome
                   window.
  4. Then I will:  Re-check the page (the agent never repeats your action),
                   then continue.
  5. To resume:    Press Enter here when you are done. If you closed this
                   terminal, run: credagent resume a-terms_checkbox
  6. Do not:       Do not close the CredAgent browser window while this
                   handoff is open.
                   Do not paste any secret or code shown on screen into chat
                   or the terminal.
==============================================================================
```
